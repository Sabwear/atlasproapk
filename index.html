Retrouvez ci-dessous les réponses aux questions les plus courantes concernant l'installation et l'utilisation de l'application.

Comment installer Atlas Pro ONTV sur Firestick ou Android TV ?

Installez l'application gratuite Downloader depuis votre store officiel, autorisez les sources inconnues dans les paramètres de votre appareil, puis entrez le code 9410522 (ONTV 4 / ATLAS PRO IBO) ou 1550791 (MAX) pour télécharger et installer l'APK.

Quelle connexion internet est recommandée pour utiliser l'application ?

Une connexion d'au moins 12 Mbps est suffisante pour une lecture fluide en HD. La fibre ou une connexion stable de 25+ Mbps est recommandée pour la 4K Ultra HD.

Sur quels appareils puis-je installer l'application ?

Le fichier APK est compatible avec les téléviseurs Android TV, Google TV, boîtiers Android Box, clés Amazon Firestick / Fire TV, ainsi que les smartphones et tablettes Android.

Le téléchargement de l'application Atlas Pro ONTV est-il gratuit ?

Oui, l'application Atlas Pro ONTV est un lecteur multimédia téléchargeable gratuitement. Vous devez disposer de vos propres identifiants ou code d'accès auprès de votre fournisseur pour charger votre contenu.
